## Викисловарь (ru.wiktionary.org)

Файл `lexicon/wiktionary-ru.json` получен из Русского Викисловаря через MediaWiki API (`https://ru.wiktionary.org/w/api.php`, `list=categorymembers` и `prop=revisions`).
Материалы Викисловаря доступны по лицензии [Creative Commons Attribution-ShareAlike 4.0](https://creativecommons.org/licenses/by-sa/4.0/deed.ru); авторы — участники Викисловаря (история правок каждой статьи: `https://ru.wiktionary.org/w/index.php?title=<статья>&action=history`). Изменения: взяты заголовок, первое значение (без разметки, сокращено до 120 символов), основы и явные словоформы из шаблонов морфологии; уровни грубости проставлены по категории и пометкам первого значения (без пометки грубости запись остаётся справочной, `level: none`, и не распознаётся). Производный файл распространяется на тех же условиях (CC BY-SA 4.0).

## Ручные списки

`lexicon/roots-ru.json`, `lexicon/en.json`, `lexicon/ro.json`, `replies/*.json` — написаны вручную для J.A.R.V.I.S. (корни, исключения-ловушки, варианты распознавателя речи, английский и румынский, похвала и извинения, банк реплик). `lexicon/user.json` — слова владельца, сборщик его не трогает.
