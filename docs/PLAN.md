## Архитектура (всё за trait-интерфейсами, чтобы менять провайдеров)
```
микрофон → VAD → STT → фильтр «Джарвис» → LLM (Groq, SSE + tools) → нормализатор речи → TTS (Xeon) → динамики
                                              ↑ tools: система/приложения/UIA · веб-поиск · память
                  события состояния/звука/текста → Tauri events → HUD (Next.js)
```
- **audio:** захват 16 кГц mono, VAD (`earshot`, кадры 16 мс), барж-ин (новая реплика обрывает ответ + `DELETE /tts/{id}`), защита от эха: пока говорит Джарвис — полу-дуплекс + фильтр эха по словам.
- **stt:** `SttEngine` — бэкенд «сервер Xeon» (после шага 0) и запасной локальный sherpa-onnx (русские модели).
- **wake word:** v1 — текстовый фильтр «Джарвис, …» по транскрипту; акустический детектор — позже.
- **llm:** `LlmProvider`, Groq `openai/gpt-oss-120b`, цикл tool-calling, системный промпт в характере дворецкого («Слушаюсь, сэр»), коротко и по-русски.
- **tts-клиент:** HTTPS с закреплённым частным CA (`src-tauri/config/xeon-tts-ca.pem` из истории), фразы ≤260 символов, ограниченная очередь PCM (≤5 буферов), раннее воспроизведение.
- **speech_normalizer:** числа, Markdown, сокращения — переносим из `HEAD~1:src-tauri/src/speech_normalizer/`.
- **tools:** `system` (время, CPU/RAM/GPU/диски, `sysinfo`), `apps` (запуск, громкость), `uia` (Windows UI Automation, клик/ввод/хоткеи, перенос из `HEAD~1:src-tauri/src/platform/windows/uia.rs`), `web_search` (провайдер за trait, ключ в `config.json`), `memory`. Опасные действия — подтверждение в HUD, аварийная остановка Ctrl+Alt+K.
- **memory:** SQLite (`rusqlite`): сессии, сообщения, факты о тебе; FTS5-поиск; инструменты `remember` / `recall`.
- **HUD (Next.js, статический экспорт в Tauri):** анимированный реактор, реагирующий на состояния (ожидание / слушает / думает / говорит) и громкость; субтитры; телеметрия; журнал вызовов инструментов и окна подтверждений.

## Этапы (после каждого есть что проверить руками)
0. **Установка инструментов, разведка и каркас.**
   - *Установить недостающее.* Уже стоят (проверено): Rust 1.100, Node 24, npm 11, git, pip, winget, WebView2. Ставлю только: замену `sshpass` (под Windows его нет) — `pip install paramiko` или `winget install PuTTY.PuTTY` (`plink -pw`), и `cargo install tauri-cli`. MSVC Build Tools — проверить при первой сборке, при отсутствии доустановить через winget.
   - SSH на Xeon (только чтение): `systemctl`, `ss -tlnp`, найти STT-службу и её API; взять Bearer-токен TTS из `/etc/jarvis-tts-rs.env`. SSH-ключ не настраиваем (решение пользователя), заходим по паролю только когда нужно. Каркас Tauri 2 + Next.js, `.gitignore`, пустой HUD. Если STT на сервере нет — решаем: поставить на Xeon (whisper/sherpa) или идти локально.
1. **Говорит.** Микрофон → VAD → STT → Groq → TTS → динамики, слово «Джарвис». *Проверка:* «Джарвис, сколько будет семь плюс пять?» → слышу «двенадцать»; первый звук быстрее ~1.5 с.
2. **HUD.** Реактор, субтитры, телеметрия. *Проверка:* визуально реагирует на все 4 состояния.
3. **Память.** SQLite + `remember`/`recall`. *Проверка:* «Запомни, что я люблю чёрный кофе» → после перезапуска «что я люблю?».
4. **Управление ПК.** Приложения, громкость, UIA, подтверждения, Ctrl+Alt+K. *Проверка:* «Открой блокнот и напиши привет».
5. **Интернет.** `web_search` + пересказ голосом. *Проверка:* «Что нового по погоде в Кишинёве?».
6. **Полировка.** Барж-ин, эхо, трей, автозапуск, тесты.

## Мои решения (можно оспорить)
Текстовый wake word в v1; режим администратора/UAC не делаем в v1; веб-поиск через внешний API-провайдер (выберем на этапе 5); на Windows нет аппаратного эхоподавления, поэтому полу-дуплекс + желательны наушники.
