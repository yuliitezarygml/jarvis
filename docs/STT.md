# Распознавание речи «как у Claude Code» + сеть в HUD — план


## Context (зачем)
Хочется, чтобы Джарвис понимал речь так же хорошо, как диктовка Claude Code. Активация остаётся **по слову «Джарвис»** (без клавиш).
Честно про Claude Code: его движок — внутренний облачный сервис Anthropic, публичного API нет, модель не названа. Скопировать нельзя — можно повторить **подход**: точная облачная модель на финальный текст + быстрый живой текст во время речи + словарь имён.

Что есть сейчас (из кода):
- Локальный **GigaAM v3** (`crates/jarvis-voice/src/stt/local.rs`) — хорош для русского, без интернета; «живой» текст — переразбор каждые 0,5 с и только первые 12 с фразы (`local.rs:25-27`).
- **Groq Whisper** уже есть (`stt/groq.rs`, модель `whisper-large-v3-turbo`, `language: ru`, целая фраза, без живого текста) — работает через твои ключи Groq.
- Выбор движка — `stt.engine`: `local` / `server` / `groq_whisper` (`stt/mod.rs:110-122`); один движок на всё.
- Живой текст идёт в HUD как `Subtitle{is_final:false}` (`pipeline.rs:685`) после слова «Джарвис».
- Никто не измерял, какой движок точнее **на твоём голосе и микрофоне**.

Плюс найденная ошибка: панель «Сеть» в HUD пишет «бэкенд пока не присылает» — ядро не считает трафик (`crates/jarvis-sys/src/resources/telemetry.rs` шлёт `Event::Telemetry{cpu, ram, gpu}` без сети, `crates/jarvis-core/src/event.rs:73`), а интерфейс ждёт `net_kbps` (`src/lib/reducer.ts:237`).

## Как будет работать (гибрид, как у Claude Code)
1. **Слушает локально (GigaAM)** — слово «Джарвис», живой текст во время речи, без интернета и задержки.
2. **Фраза закончилась → финальный текст из облака** (точная модель) — параллельно с локальным; кто первый с хорошим результатом, тот и идёт в команду:
   - ответ облака пришёл ≤ 1,5 с → берём облачный текст (точнее);
   - облако не ответило/лимит/нет интернета → берём локальный (Джарвис не «зависает»);
   - журнал пишет, какой движок дал текст и за сколько мс.
3. **Подсказка-словарь для облака**: названия программ и сайтов, которые ты говоришь (VS Code, GitHub, Discord, Steam…), буквы дисков, твои частые слова из памяти → параметр `prompt` (Whisper это поддерживает). Меньше «вэс код» и «комид».
4. **Живой текст на всю фразу**: локальный переразбор не только первые 12 с, а всю фразу (шаг 0,4 с), показ в HUD и виджете в углу сразу после «Джарвис».

## Какой облачный модуль
| Движок | Ключ | Русский | Живой текст | Решение |
|---|---|---|---|---|
| **Groq Whisper large-v3** (не turbo — точнее) | твой Groq, бесплатно | хорошо | нет (финал за ~0,3–0,8 с) | **по умолчанию** |
| Groq Whisper large-v3-turbo | твой Groq | чуть хуже, быстрее | нет | запасной |
| GigaAM v3 локально | не нужен | очень хорошо | да (имитация) | живой текст + запасной финал |
| OpenAI gpt-4o-transcribe / Deepgram Nova-3 / ElevenLabs Scribe | нужен новый платный ключ | очень хорошо | Deepgram/OpenAI — да | **позже, по желанию**: адаптер по тому же интерфейсу `SttEngine` |

Итоговый выбор по умолчанию — **по замеру на твоём голосе** (ниже), а не наугад: если GigaAM окажется точнее Whisper на твоих фразах, гибрид останется локальным.

## Замер точности на твоём голосе
- Настройки → «Распознавание речи» → **«Проверить на моём голосе»**: экран показывает 20 фраз (команды Джарвиса, названия программ, числа, английские слова, адреса), ты читаешь их, Джарвис записывает (WAV в `data/stt-check/`, только локально).
- Прогон всех движков → таблица: **% ошибок в словах (WER)**, ошибки в названиях, время ответа. Кнопка «Сделать лучший движком по умолчанию».
- То же из консоли: `cargo run -p stt-bench -- data/stt-check` (для меня — сравнивать версии).

## Что меняется в коде
- `crates/jarvis-core/src/config.rs` `SttConfig`: `engine` = `local` / `groq` / **`hybrid`** (новое, по умолчанию после замера), `cloud_model` (`whisper-large-v3`), `cloud_timeout_ms` (1500), `language` (`ru`), `hints: Vec<String>` (свои слова). Старые значения работают как раньше.
- `crates/jarvis-voice/src/stt/`:
  - `hybrid.rs` (новое) — `HybridStt`: поток и живой текст от локального, финал — гонка облако vs локальный с таймаутом, отмена облачного запроса при перебивании; реализует `SttEngine`, поэтому `pipeline.rs` почти не меняется (`engine_from_config` + новая ветка).
  - `groq.rs` — модель из конфига, `prompt` со словарём, повтор при 429 через второй ключ Groq (у тебя их два).
  - `local.rs` — живой текст на всю фразу (убрать предел 12 с, шаг 0,4 с, не чаще, чем успевает процессор).
- Словарь подсказок: из `crates/jarvis-sys` (`open/catalog.rs` — названия программ/настроек) + `hints` из конфига + имена из памяти (факты категории alias/contact).
- `tools/stt-bench` (новое, Rust) — прогон движков по папке WAV + эталонные тексты → WER/CER/время.
- UI `src/components/settings/tabs.tsx` раздел «Распознавание речи»: выбор движка с пояснениями (локально / облако / гибрид), модель облака, «свои слова», мастер «Проверить на моём голосе» с таблицей. В журнале — какой движок дал текст.
- **Сеть в HUD**: `telemetry.rs` — sysinfo `Networks`, байты принято+отправлено за интервал → кбит/с; `Event::Telemetry` + поле `net_kbps: Option<f32>`; `src-tauri/src/sink.rs` и тесты; интерфейс уже готов (`reducer.ts:237`, `Telemetry.tsx:64`).

## Проверка
- Тесты: гибрид (облако быстрее → облачный текст; облако упало/таймаут → локальный; перебивание отменяет запрос), подсказки в запросе Groq, переключение ключа при 429, конфиг старого вида, подсчёт WER, сеть в событии телеметрии (> 0 при трафике).
- Живая проверка: синтезирую голосом Джарвиса 20 фраз (как делали с матом) → `stt-bench` по всем движкам → таблица; потом ты сам проходишь «Проверить на моём голосе».
- HUD: панель «Сеть» показывает скорость, график двигается при скачивании.
- `cargo test --workspace`, `npm test`, `npx tsc --noEmit`.

## Важно знать
- Гибрид отправляет запись **каждой команды после «Джарвис»** в облако Groq (как Claude Code отправляет в Anthropic). Само ожидание слова «Джарвис» остаётся локальным — фоновые разговоры никуда не уходят. Можно выключить: движок «Локально».
- Бесплатный лимит Groq на распознавание — отдельный от модели «мозга»; при упоре — автоматически локальный.
